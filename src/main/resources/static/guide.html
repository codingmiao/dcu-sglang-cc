使用说明

经过一段时间的调优，目前已经能完成基本的编码任务了。对 Claude Code 完成了输入输出适配，欢迎各位试用。 特别地，写文档等非编码工作的大佬们也可以试用下，给我整点非编码场景的训练数据 🐶。

~90 token/s

~600 token/s
8 个并发请求

使用方法

  1. 安装 Node.js 18 或更新版本
  2. 安装 Claude Code
    npm install -g @anthropic-ai/claude-code
  3. 编辑或新增 settings.json
    macOS & Linux：~/.claude/settings.json
    Windows：用户目录/.claude/settings.json 
    {
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "<your_api_key>",
    "ANTHROPIC_BASE_URL": "xxx/dcu-sglang-cc",
    "API_TIMEOUT_MS": "3600000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "131072"
  },
  "tui": "fullscreen"
}
    your_api_key 需联系管理员申请。

启动 Claude Code

在终端进入你的项目目录后执行：
claude                 # 启动交互式会话
claude "帮我写个脚本"    # 直接带任务启动
claude -c              # 继续上一次会话
claude -r              # 选择并恢复历史会话

常用操作

操作说明
/help查看所有可用命令
/clear清空当前上下文，重新开始
/compact压缩上下文（保留要点，释放空间）
/model切换模型
/cost查看本次会话 token 用量
/init为当前项目生成 CLAUDE.md 项目说明
/memory编辑记忆文件
/status查看当前状态
/quit退出
其它常用：Shift+Tab 切换自动接受 / 计划模式；Esc 中断当前操作； # 开头写入记忆；! 开头直接执行 shell 命令；@ 引用文件。
